# GİZ GURME CMS

GitHub Pages + Supabase ile çalışan telefon uyumlu menü ve reçete yönetim sistemi.

## Dosyalar
- index.html
- styles.css
- app.js
- config.js
- setup.sql
- manifest.webmanifest

## Kurulum
1. setup.sql dosyasını Supabase SQL Editor'da çalıştırın.
2. Supabase Project Settings > API bölümünden Project URL ve anon public key değerlerini alın.
3. config.js içindeki iki alanı doldurun.
4. Bu dosyaların tamamını GitHub deponuzun köküne yükleyin.
5. GitHub Settings > Pages > Deploy from branch > main / root seçin.
